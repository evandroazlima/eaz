# Framework de Domínio — Conteúdo de Educação Cripto

Este arquivo define o framework operacional para criação de conteúdo de educação em criptomoedas,
arbitragem e DeFi — específico para o mercado brasileiro e para a marca EAZ Educação.

---

## Framework de Criação de Conteúdo Cripto

### 1. O Framework NEWS → ANGLE → CONTENT

Todo conteúdo educativo de alta performance começa com uma notícia ou acontecimento real do mercado,
não com um tema genérico. A sequência é sempre:

**NOTÍCIA** → (o que aconteceu no mercado) → selecionada pelo usuário
**ÂNGULO** → (como isso se conecta ao público) → 5 opções geradas por Ivan Ideia
**CONTEÚDO** → (o que o público deve aprender/fazer) → produzido pelos criadores

Esta sequência garante que o conteúdo é relevante, atual e conectado com o mundo real.
Conteúdo genérico ("7 dicas para cripto") tende a ter alcance menor que conteúdo baseado em eventos reais.

### 2. Os 5 Ângulos Padrão para Conteúdo Cripto

Para qualquer notícia de mercado, existem 5 perspectivas principais que geram engajamento:

| Ângulo | Emoção-base | Hook tipo | Melhor formato |
|--------|-------------|-----------|----------------|
| 🔴 Medo/Proteção | Medo de perder | "Como se proteger de..." | Carrossel, LinkedIn |
| 🟢 Oportunidade | Ganância/esperança | "Essa é a janela antes que..." | Reels, Carrossel |
| 📚 Educacional | Curiosidade | "O que X significa na prática" | Carrossel, YouTube |
| ↔️ Contrário | Indignação/surpresa | "O que ninguém te conta sobre..." | LinkedIn, Reels |
| ⭐ Inspiracional | Esperança | "Esse aluno fez X — você pode também" | YouTube, Carrossel |

### 3. Estrutura de Carrossel Cripto de Alta Performance

**Slide 1 (Hook/Capa):**
- Título provocador com número ou dado específico
- Máximo 15 palavras
- Fundo escuro + texto claro OU fundo claro com accent laranja/verde (cores de mercado)
- Texto: "Salva esse post — você vai precisar"

**Slides 2-8 (Corpo):**
- Um conceito por slide
- Headline (48px+) = a sacada principal do slide
- Texto de suporte (34px+) = dado, exemplo, ou explicação
- Mínimo 40 palavras por slide
- Use dados reais: porcentagens, valores em R$, tempo de operação

**Slide final (CTA):**
- CTA keyword: "Comenta ARBITRAGEM que te mando o guia" ou "Salva para ter no bolso"
- Handle @evandroaz
- Link bio opcional

### 4. Framework de Script para Reels Cripto (15-30 segundos)

**0-2s (Hook visual + textual):**
- Texto na tela: a pergunta ou afirmação mais provocadora
- Falado: mesma frase ou complemento
- Objetivo: fazer a pessoa parar de deslizar

**2-8s (Contexto rápido):**
- Qual notícia/situação de mercado motiva o conteúdo
- 1-2 frases, máximo
- Número concreto se possível ("Bitcoin caiu 8% em 24h")

**8-22s (Entrega do valor):**
- 3-5 pontos rápidos OU um processo simplificado
- Cortes a cada 3-5 segundos para manter ritmo
- Texto na tela em cada ponto principal

**22-30s (CTA + Loop):**
- CTA específico ("Comenta CRIPTO aqui embaixo")
- Último frame fecha de forma que estimula replay

### 5. Framework de Script YouTube (8-15 minutos)

**0-30s (Hook):**
- Promete o resultado do vídeo de forma específica
- Mostra prova visual se possível (gráfico, tela de operação)
- Cria open loop: "Mas antes de chegar lá, preciso te contar..."

**30s-1min (Contexto + Credibilidade):**
- Por que esse tópico é importante AGORA
- Uma linha de credibilidade natural (não forçada)

**1-8min (Corpo em 3-5 seções):**
- Cada seção = uma sacada ou passo do processo
- Pausa de padrão a cada 60-90s (B-roll, gráfico, exemplo visual)
- Ponto climático aos 60-70% do vídeo = a sacada mais valiosa

**8-13min (Aplicação prática):**
- Demonstração real ou exemplo passo a passo
- Dados e números específicos

**Último minuto (Recap + CTA):**
- 3 pontos principais revisitados rapidamente
- 1 CTA único: próximo vídeo, link bio, comentar

### 6. Framework de Post LinkedIn (Autoridade Profissional)

**Linha 1-2 (Hook antes do "ver mais"):**
- Afirmação contrária, dado surpreendente, ou história pessoal
- Máximo 210 caracteres
- Cria dissonância cognitiva imediata

**Parágrafos 3-6 (Desenvolvimento):**
- Tom pessoal: "Eu aprendi que...", "Na minha experiência..."
- Parágrafos de 1-2 linhas com espaçamento entre eles
- Dados quando disponíveis, mas linguagem humana

**Bullet points (Insights acionáveis):**
- 3-5 pontos numerados
- Cada ponto = uma sacada que o leitor pode usar imediatamente

**CTA final:**
- Pergunta genuína que convida debate: "O que você acha disso?"
- Ou: "Qual dessas estratégias você já tentou?"
- Máximo 3 hashtags no final

## Princípios de Qualidade EAZ Educação

### O que diferencia conteúdo premium de conteúdo genérico no nicho cripto:

1. **Especificidade vs. vagueza** — "A arbitragem entre Binance e Mercado Bitcoin gerou 2,3% de spread hoje" bate "arbitragem pode ser lucrativa".

2. **Método vs. promessa** — Mostrar O COMO, não apenas O QUANTO. O público é cético com promessas; o método é o diferencial.

3. **Contexto de mercado** — Sempre conectar ao que está acontecendo hoje. Cripto é volátil, o conteúdo precisa ser atual.

4. **Segurança como pilar** — A mensagem EAZ nunca é "fique rico rápido". É "opere com método, reduza risco, gere renda consistente".

5. **Acessibilidade** — O público vai de iniciantes curiosos a intermediários operando. O conteúdo deve ser acessível ao iniciante sem desrespeitar o intermediário.
