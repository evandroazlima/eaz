# Critérios de Qualidade — EAZ Social Media Squad

Este arquivo define os critérios de avaliação para todos os formatos produzidos pelo squad.
A Revisora Vera Veredito usa este documento como rubrica de pontuação.

---

## Critérios Globais (Aplicados a Todos os Formatos)

| Critério | Peso | Descrição | Score mínimo para APROVAÇÃO |
|----------|------|-----------|----------------------------|
| Alinhamento com a marca EAZ | Alto | Conteúdo reflete os valores da EAZ: método, segurança, resultados práticos. Nunca promete ganho garantido. | 7/10 |
| Precisão factual | Alto | Dados de mercado, porcentagens e afirmações são verificáveis e corretos. Nenhuma afirmação não comprovável. | 8/10 |
| Ângulo e hook | Alto | O ângulo é claro, o hook para o scroll e cria razão para continuar lendo/assistindo. | 7/10 |
| Tom de voz | Médio | O tom selecionado pelo usuário é mantido do início ao fim. Sem quebras de voz no meio do conteúdo. | 7/10 |
| CTA | Médio | Existe um CTA específico e acionável. Não genérico ("siga-me"), mas com keyword ou ação clara. | 7/10 |
| Atualidade | Médio | O conteúdo é ancorado em notícia ou dado atual do mercado. Sem conteúdo genérico "evergreen" desconectado de contexto. | 6/10 |

**Regra de rejeição automática:** Qualquer critério com score < 4/10 = REJEITAR imediatamente.
**Regra de aprovação:** Score médio >= 7/10 E nenhum critério < 4/10 = APROVAR.

## Critérios Específicos por Formato

### Instagram Carrossel

| Critério | Descrição | Score mínimo |
|----------|-----------|-------------|
| Slide 1 (Hook visual) | Para o scroll. Título provocador ≤ 15 palavras. | 8/10 |
| Densidade por slide | 40-80 palavras por slide. Hierarquia: headline + suporte. | 7/10 |
| Narrativa progressiva | Cada slide avança a história. Sem repetição entre slides. | 7/10 |
| CTA no slide final | Keyword específica ("Comenta ARBITRAGEM"). Handle @evandroaz. | 8/10 |
| Caption (125 chars) | Primeiros 125 chars funcionam como hook autônomo antes do "ver mais". | 7/10 |
| Hashtags | 5-15 hashtags. Mix niche + mid-range + broad. Sem spam. | 6/10 |
| Design (quando aplicável) | Slides em HTML/CSS com design system consistente. Texto ≥ 34px. | 7/10 |

**Veto automático:** Slides com < 40 palavras sem justificativa | Sem CTA no slide final | Caption sem hook nos 125 chars

### Instagram Reels (Script)

| Critério | Descrição | Score mínimo |
|----------|-----------|-------------|
| Hook (0-2s) | Texto na tela + falado. Para o scroll imediatamente. | 9/10 |
| Duração | 15-30 segundos para máxima taxa de conclusão. | 8/10 |
| Direção visual | Cortes/ângulos a cada 3-5 segundos. Ritmo dinâmico. | 7/10 |
| Legendas | Especifica legendas/subtítulos burned-in para consumo sem som. | 8/10 |
| Loop design | Fim conecta ao início para estimular replay. | 6/10 |
| CTA | Específico e único. | 7/10 |

**Veto automático:** Intro lenta (sem hook nos 2 primeiros segundos) | Sem especificação de legendas | CTA genérico

### YouTube (Script)

| Critério | Descrição | Score mínimo |
|----------|-----------|-------------|
| Título | 50-70 chars. Curiosity gap + benefício específico. Keyword na frente. | 8/10 |
| Thumbnail concept | Descrito com rosto/expressão, texto overlay 3-4 palavras, esquema de cores. | 8/10 |
| Hook (0-30s) | Estabelece stakes, promete resultado, cria open loop. Sem "oi pessoal". | 9/10 |
| Padrões de interrupção | Marcados a cada 30-60s (B-roll, gráfico, zoom). | 7/10 |
| Clímax posicionado | Sacada mais valiosa em 60-70% do vídeo. | 7/10 |
| Duração estimada | 8-15 minutos. | 7/10 |
| Descrição + timestamps | Primeiras 2 linhas com hook + keywords. Timestamps marcados. | 7/10 |
| CTA único | Apenas 1 CTA no final do vídeo. | 8/10 |

**Veto automático:** Hook sem estabelecer stakes em 30s | Título > 100 chars | Sem thumbnail concept | CTA pedindo like/sub antes de entregar valor

### LinkedIn Post

| Critério | Descrição | Score mínimo |
|----------|-----------|-------------|
| Hook (≤ 210 chars) | Funciona antes do "ver mais". Contrário, dado surpreendente, ou história pessoal. | 9/10 |
| Voz em 1ª pessoa | "Eu aprendi", "Eu testei". Sem "deve-se" ou tom genérico. | 8/10 |
| Parágrafos curtos | 1-2 linhas por parágrafo. Espaçamento entre todos. | 7/10 |
| Insights numerados | 3-5 bullets acionáveis. | 7/10 |
| Pergunta genuína | CTA é pergunta específica que convida resposta pessoal. | 7/10 |
| Sem link no corpo | Links sempre em comentário, nunca no corpo do post. | 9/10 |
| Hashtags | 3-5, no final, relevantes ao nicho cripto/finanças. | 6/10 |

**Veto automático:** Link no corpo do post | Sem hook nos 210 chars | Tom genérico ou corporativo

### Design Visual (HTML/CSS)

| Critério | Descrição | Score mínimo |
|----------|-----------|-------------|
| Sistema de design | Cores, fontes, espaçamento definidos antes dos slides. | 8/10 |
| Tamanho de fonte | Mínimo 34px body, 43px heading, 58px hero (Instagram). | 9/10 |
| Contraste WCAG | Todos os textos com contraste ≥ 4.5:1. | 8/10 |
| HTML autônomo | CSS inline only. Sem dependências externas (exceto Google Fonts). | 9/10 |
| Viewport correto | body { width: 1080px; height: 1440px } para Instagram carousel. | 9/10 |
| Verificação visual | Primeiro slide renderizado e verificado antes do batch. | 8/10 |
| Sem slide counter | Sem texto "1/8", "7/8" ou similar nos slides. | 9/10 |

**Veto automático:** Fonte < 20px | Sem verificação do primeiro slide | Dependências externas além de Google Fonts

## Escala de Pontuação

| Score | Significado |
|-------|-------------|
| 9-10 | Excelente — supera expectativas |
| 7-8 | Bom — atende todos os critérios |
| 5-6 | Regular — atende parcialmente, pode precisar de ajuste |
| 3-4 | Ruim — falha em critério importante |
| 1-2 | Crítico — falha grave, rejeitar imediatamente |

## Veredito Final

- **APROVAR**: média geral ≥ 7/10 E nenhum critério < 4/10
- **APROVAR CONDICIONAL**: média ≥ 7/10 MAS algum critério não-crítico entre 4-6/10 → listar correções obrigatórias
- **REJEITAR**: média < 7/10 OU qualquer critério crítico < 4/10
- **ESCALAR**: após 3 ciclos de revisão com os mesmos problemas → apresentar ao usuário para decisão
